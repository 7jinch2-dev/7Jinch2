## 三、核心设计思路

这套作品集真正的核心不是单个动画，而是把“浏览简历”改造成“走进一间设计师的店”。

空间与信息一一对应：

| 空间物件 | 承担的内容 |
| --- | --- |
| 店面、玻璃窗、双开门 | 主视觉与进入作品的入口 |
| 售货机五层货架 | 按类别陈列作品，未来保留“新品/彩蛋层” |
| 店员和工牌 | 姓名、职位、联系方式、简历下载 |
| 收银台、小本子 | 兴趣、日常、个人性格 |
| 收银机和小票 | 合作方式、PDF、联系方式 |
| 墙面证书 | 学历、荣誉、技能和工具 |
| 后场工作台、档案柜、草图墙 | 项目过程、失败稿、设计方法 |

它把传统作品集里的几个信息模块，翻译成有物理感、可以点击和探索的物件。

另一条主线是“用作品陈列方式表达设计能力”：

- 开屏用实体仪器而不是普通大标题；
- 分类用售货机玻璃球而不是标签按钮；
- 作品切换用带透镜扭曲的实体卡片；
- 个人信息用全息会员卡；
- 页面身份用可甩动的工牌。

这些交互共同传达的是“多媒介、三维、动效和全流程设计能力”，而不是单纯炫技。

## 四、概念演进过程

### v0.1：夜晚第一人称

概念图：

`concepts/store/scene-bible-v01.png`

关键词是“夜晚、第一人称、便利店、暖光、低多边形”。

剧情被拆成五段：

1. 门口；
2. 推门；
3. 挑货；
4. 结账；
5. 后场。

镜头约 7 个机位、40 秒，采用轨道式第一人称移动，不允许自由 WASD，主要用点击和短距离推进控制节奏。

### v0.2：双区空间与六段剧情

概念图：

`concepts/store/scene-bible-v02.png`

进一步明确“前店 + 后场工作室”的双区结构，并细化了：

- 街角、窗边、进店、挑货、结账、后场 6 段剧情；
- 8 个镜头；
- 暖光区与冷光区的分区；
- 木、玻璃、纸、金属的材质方向；
- 低多边形店员、工牌、耳机和半身动作；
- 8 个镜头的时长和推镜方式。

### v0.3：点开每一个物件

概念图：

`concepts/store/scene-interaction-v03.png`

从“剧情漫游”转向“可点击信息空间”：

- 外景只有两个动作：窗口对话、推门；
- 店内所有东西都能点；
- 9 个物件对应 9 块真实内容；
- 点击物件后镜头推进，再显示内容；
- `Esc` 始终可以退回；
- 核心流程变成：外景 → 气泡 → 开门 → 店内全景 → 物件特写 → 内容层。

### v0.4：3D 微俯视 + 售货机即货架

概念图：

`concepts/store/scene-v04.png`

这是后来落地时最重要的方向：

- 不再做完全沉浸的第一人称，而采用略高、略俯的 3D 微缩模型视角；
- 售货机从普通道具升级为整个作品集的内容货架；
- 五层分别放 UI、详情、IP、游戏和彩蛋/新品；
- 点击层级后，镜头拉近约 `1s`，再选择单件作品；
- 基础镜头角约 `18°`，点开物件后可暂时转到 `25–30°`；
- 手机端沿用同一构图，降低阴影和光斑强度。

### 实际代码灰模

`site/_blockout/blockout.js`

先把 v0.4 的核心动作做出来，只验证三件事：

1. 空间体块是否成立；
2. 机位是否足够讲清内容；
3. 点击和镜头推进是否顺畅。

这一步刻意没有做材质、贴图和角色动画，避免在交互结构未定时过早美化。

### 最终网页

最终网页并没有直接嵌入整间 3D 店铺，而是保留了其中更容易稳定落地的部分：

- 用复古展示柜承担开屏记忆点；
- 用 2.5D 售货机承担作品分类；
- 用透视卡片轮播承担作品浏览；
- 用 3D 灰模保留为独立概念原型。

这是一种折中：保留“店/售货机/实体物件”的叙事，同时避免整站 3D 带来的性能、移动端和内容维护风险。

│   └── components/       # 售货机、轮播、工牌、全息卡
└── references/           # 唯一保留的设计参考与提取图
