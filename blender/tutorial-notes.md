## 从教程中提取的方法

- 先用简单立方体确定头部体积，不一开始就追求完整轮廓；
- 使用 Subdivision Surface 让低面数体块快速成为连续曲面；
- 使用环切增加控制线，再通过移动、挤出和缩放塑造额头、眼窝、下巴与后脑；
- 使用内插面建立眼睛、嘴和五官需要的局部拓扑；
- 暂时隐藏后脑区域，便于在正视图处理面部，之后恢复隐藏对象；
- 将角色三视图作为参考图放在正视图后方，按轮廓逐步贴合；
- 头发先按外轮廓分区，再逐步整理成发束，而不是直接堆大量圆柱；
- 五官和头发都在较低的面数上调整大形，最后才提高细分和光滑度。

## 常用快捷键

| 快捷键 | 用途 |
| --- | --- |
| `Ctrl+2` | 添加二级细分曲面 |
| `Ctrl+R` | 环切，增加结构线 |
| `E` | 挤出 |
| `S` | 缩放 |
| `I` | 内插面 |
| `H` | 隐藏选中区域 |
| `Alt+H` | 恢复全部隐藏区域 |
| 小键盘 `1` | 进入正视图，方便放置参考图 |

## 在店员模型中的应用

- 头部改为连续截面网格，再用两级细分平滑；
- 夹克躯干由肩到腰建立连续截面；
- 袖子从肩部宽截面自然收至袖口；
- 裤腿从大腿、膝部到脚踝使用连续曲面，不再使用圆角长方体；
- 头发使用曲线发束和顶点色渐变，分成黑色发根、深青中段和亮青发梢。

当前模型仍以程序化网格为主，适合继续在 `.blend` 文件中手动雕刻头部或重新布线。
